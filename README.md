# 🛡️ LKPD Interaktif — Misi Keamanan Digital

**SMP Negeri 19 Kota Bekasi · Informatika Kelas 9 · Fase D · Pertemuan 15**

Aplikasi LKPD (Lembar Kerja Peserta Didik) berbasis web yang menggabungkan
game sederhana + interaktif untuk materi **Malware, Phishing, DoS, dan Mitigasi**.

---

## ✨ Fitur

- 🎮 **5 Misi Interaktif** — Kuis, Cocokkan, Benar/Salah, Detektif Kasus, Checklist
- 🌐 **Dwibahasa (ID ↔ EN)** — Semua istilah Inggris memiliki padanan Indonesia
- 💾 **Auto-Save** — Progres tersimpan di localStorage browser
- 📄 **Unduh Hasil** — Rekap nilai + refleksi dalam format .txt
- 🏆 **Predikat & Badge** — A/B/C/D + lencana digital
- 📚 **Glosarium** — 13 istilah teknis dengan penjelasan
- 🔊 **Efek Suara** — Web Audio API (tanpa file eksternal)
- 📱 **Responsive** — Optimal di HP, tablet, dan laptop
- ♿ **Aksesibilitas** — WCAG AA, keyboard-friendly
